# 宝塔面板操作对照（Ubuntu/Debian）

> 前提：服务器装好宝塔（bt）面板。以下均可在面板 GUI 完成，脚本只负责安装程序本身。

## 1. 端口放行（最重要）

宝塔「安全」页 + 云厂商安全组**两层都要配**：

| 端口 | 放行？ | 说明 |
|---|---|---|
| 7000/tcp | ⚠️ 仅 frp 回退模式需要（内置隧道模式下**关闭**） | frp 控制端口，笔记本 frpc 连入；切到内置隧道后隧道走 443，不再需要 |
| 443/tcp | ✅ 放行 | HTTPS 入口 |
| 80/tcp | ✅ 放行 | Let's Encrypt 验证（有域名时） |
| **3080/tcp** | ❌ **严禁放行** | DSH 隧道端口——放行 = 把笔记本 DSH 暴露公网（可执行任意命令） |
| 3090/tcp | ❌ 不放行 | 网关只监听 127.0.0.1，由 Nginx 反代 |

## 2. 反向代理（把 https://域名或IP 转发到网关）

路径：**网站 → 添加站点**（域名填你的域名；无域名时先随便填个，如 `dsh.local`，下面改 IP 或直接手动 Nginx）

- 添加后进入站点 → **反向代理** → 添加：
  - 代理名称：`dsh-gateway`
  - 目标 URL：`http://127.0.0.1:3090`
  - 发送域名：留空
- 宝塔生成的 Nginx 配置会自动带 `Upgrade` 头吗？——**不一定**。进入站点 → 配置文件，确认 location 里包含：

```nginx
proxy_set_header Upgrade $http_upgrade;
proxy_set_header Connection "upgrade";
```

如果没有，手动加上（WebSocket `/ws` 需要）。也可以直接用仓库里的 `product/server/nginx-dsh-gateway.conf` 替换该站点的 server 块（改占位符）。

## 3. SSL 证书

- **有域名**：站点 → SSL → Let's Encrypt → 一键签发（需域名 A 记录已指向服务器 IP，80 端口可访问）。
- **无域名（纯 IP）**：Let's Encrypt **无法**为 IP 签发（HTTP-01 验证需要域名）。用 `install.sh --selfsigned <公网IP>` 生成自签证书（SAN 含该 IP），然后在 宝塔 SSL → 其他证书 里粘贴 cert/key；手机端需安装信任该证书（见 [部署指导](./部署指导.md) §2.4）。
  - 备选：先用 `http://IP:3090` 不配 TLS 内网验证流程（手机与服务器同网段时），再补 TLS。

## 4. Node 环境（网关）

推荐用仓库脚本 `product/server/install.sh`（自动装 Node + npm ci + build + systemd）。
宝塔也有「Node 项目」功能可托管（入口：网站 → Node 项目 → 添加），但 systemd 更可控，脚本已配好。

## 5. 查看日志 / 状态

- 部署状态 + 安全核查：`dsh-deploy --status`
- 网关：宝塔「终端」或 SSH：`journalctl -u dsh-gateway -n 50 -f`
- frps：`journalctl -u frps -n 30`

## 6. 常见坑

1. **云安全组没放行 7000**，但宝塔防火墙放了——frpc 仍连不上（两层都要放；内置隧道模式不需要 7000）；
2. **3080/3081 被放行**——立即关掉，否则笔记本 DSH 裸奔公网；
3. 自签证书手机访问提示不安全——需先安装证书，或换有域名的 Let's Encrypt；
4. 反代后 WebSocket 连不上——检查 `Upgrade` 头是否在配置里（见 §2）。
