# DSH Link 三端部署与构建指南（具体操作）

> 面向执行：从零把服务器、PC、手机三端部署/构建好并联调。每步给命令 + 说明 + 预期。
> 环境：服务器（宝塔 Ubuntu24 2核2G）、PC（Windows 11）、手机（Android）。
> 相关：需求-DSH远程接入网关.md · 设计-DSH远程接入网关.md · 绑定协议.md

---

## 〇、架构与准备

```
手机 App ──HTTPS──▶ 服务器(网关 3090 + frps 7000) ◀──frp 隧道── PC(DSH web 3080)
```

| 端 | 目录 | 关键产物 |
|---|---|---|
| 服务器 | `product/server/` | `install.sh` + `gateway/`（网关代码） |
| PC | `product/pc/` | `npm run dist` 生成的 exe |
| 手机 | `product/android/` | `gradlew assembleDebug` 生成的 APK |

**准备**：服务器公网 IP、SSH/宝塔登录、frp/网关强密码、手机 Android Studio。

## 一、服务器端：部署与更新

### 1.1 拉取代码（一次性）

服务器上的代码从 **Gitee 私有仓库** clone，路径固定：

```
/www/wwwroot/117.72.10.87/26-009DSHlink/     ← git 工作区
└─ product/server/
   ├─ install.sh      # 首次安装脚本
   ├─ deploy.sh       # 日常更新脚本（git 拉取 + 校验 + 回滚）
   └─ gateway/        # 网关源码（Node）
```

完整接入步骤（Gitee 建仓、服务器部署密钥、clone）见 **[服务器部署-git.md §2](./服务器部署-git.md)**。

### 1.2 一键安装

```bash
cd /www/wwwroot/117.72.10.87/26-009DSHlink
bash product/server/install.sh --install --ip 你的公网IP --admin admin --password 你的强密码
```
脚本自动：装 Node → frps → 网关（npm ci + build）→ systemd 自启 → 健康检查 → **打印连接串**。
**保存连接串**：
```
dsh-gw://IP?frpPort=7000&gwPort=8443&frpToken=...&gwUser=admin&gwPass=...&pair=...
```

验证：
```bash
systemctl status dsh-gateway frps --no-pager | head -8   # 两个 active
curl -s http://127.0.0.1:3090/healthz                     # {"ok":true}
```

### 1.3 宝塔：端口 / 反代 / SSL

**① 端口放行**（宝塔「安全」页 + 云安全组，两层）：
- 放行 `7000`、`8443`；**严禁放行 `3080`**（DSH 隧道端口）

**② 反向代理**：网站 → 添加站点（域名随意如 `dsh.local`，**端口 8443**）→ 站点 → 反向代理 → 目标 `http://127.0.0.1:3090` → 在生成的 conf 里确认/添加：
```nginx
proxy_set_header Upgrade $http_upgrade;
proxy_set_header Connection "upgrade";
```
站点配置开头应为 `listen 8443 ssl;`（先手动改或配 SSL 后自动）。

**③ SSL（自签，无域名）**：
```bash
bash install.sh --selfsigned 117.72.10.87        # 生成 /etc/nginx/ssl/dsh-gateway.crt/key
```
站点 → SSL → 其他证书 → 粘贴 crt / key → 保存。

**④ 验证**：
```bash
curl -k https://127.0.0.1:8443/healthz -s -o /dev/null -w "%{http_code}\n"   # 200
```

### 1.4 服务器更新（改网关后）

```powershell
# 本机：改 product/server/gateway/ 代码 → 递增 gateway/package.json 的 version → 推送
cd D:\_Projects\26-009DSHplugin
git add -A && git commit -m "网关：xxx" && git push
```

```bash
# 服务器：一条命令（git 拉取 → 构建 → 校验 → 失败自动回滚）
dsh-deploy
```

或不用便利命令：

```bash
bash /www/wwwroot/117.72.10.87/26-009DSHlink/product/server/deploy.sh
```

更新保留 `/etc/dsh-gateway`、`/var/lib/dsh-gateway`，**PC/手机无需重绑**。
回滚：`dsh-deploy --rollback`。完整说明见 **[服务器部署-git.md](./服务器部署-git.md)**。

## 二、PC 端：构建、安装与更新

### 2.1 准备

```powershell
cd D:\_Projects\26-009DSHplugin\product\pc
npm install
```

### 2.2 开发运行（调试）

```powershell
npm start
```
打开窗口 → 添加服务器粘贴连接串 → 软件自动拉起 DSH + frpc 隧道 → 显示手机配对二维码。

### 2.3 打包独立 exe（分发）

```powershell
# 国内加速（首次打包要下载工具）
$env:ELECTRON_BUILDER_BINARIES_MIRROR = "https://npmmirror.com/mirrors/electron-builder-binaries/"
$env:ELECTRON_MIRROR = "https://npmmirror.com/mirrors/electron/"

npm run dist
```
产物在 `pc\dist\`：
- `DSH Link Setup <版本>.exe` —— 安装包（推荐）
- `DSH Link <版本>.exe` —— 便携版
- `win-unpacked\DSH Link.exe` —— 解压版

### 2.4 安装/使用

双击 `DSH Link Setup.exe` 安装（或便携版直接运行）。首次用「添加服务器」粘贴连接串。`frpc.exe` 软件会自动下载（Defender 可能拦截 → 加白名单，或浏览器下载放 `pc\frpc-bin\`）。

### 2.5 PC 更新

改 `main.js`/`renderer/` 等 → `npm start` 自测 → `npm run dist` → 用新 exe 覆盖（数据在 `%APPDATA%\DSH Link`，不丢）。

## 三、手机端：构建、安装与更新

### 3.1 构建 APK（Android Studio）

1. Android Studio → **Open** → 选 `D:\_Projects\26-009DSHplugin\product\android`；
2. 等 **Gradle Sync** 完成（首次下载依赖，慢可加阿里镜像）；
3. **Build → Build APK(s)**；
4. 产物：`android\app\build\outputs\apk\debug\app-debug.apk`。

也可以命令行：
```powershell
cd D:\_Projects\26-009DSHplugin\product\android
.\gradlew.bat :app:assembleDebug
```

### 3.2 安装

- 数据线/AS Run，或把 `app-debug.apk` 传到手机安装（允许"未知来源"）；
- 首次打开：扫 PC 软件二维码（或粘贴连接串）→ 登录（TOTP 首次录入）→ 进入主页。

### 3.3 手机更新

改 `app/` 下 Kotlin 代码 → 重新 `assembleDebug` → 覆盖安装（绑定/登录状态在 DataStore，保留）。

## 四、三端联调（验证通不通）

1. 服务器：`curl -k https://IP:8443/healthz` → 200；
2. 隧道：PC 软件「隧道」灯绿；服务器 `ss -ltn | grep 3080` 有监听；
   认证链路：`journalctl -u dsh-gateway | grep "\[dsh\] auth"` 应出现 `auth=launch-token ✓ cookie=set`
   （DSH 0.1.2+ 的 `/api` 强制会话认证，未认证探测一律 401；token 由 PC 端自动上报，见部署指导）；
3. 手机：登录 → 主页会话列表显示笔记本 DSH 的会话；
4. 对话：发消息 → 流式回复；
5. 审批：触发工具 → 手机弹「允许一次/拒绝」。

## 五、常见问题速查

| 端 | 现象 | 处理 |
|---|---|---|
| 服务器 | `502 Bad Gateway` | 网关可能崩（内存），`systemctl status dsh-gateway` + 限堆 `--max-old-space-size=512`（见 systemd 单元），重启 |
| 服务器 | frps 起不来 `unknown field enable` | 删 `frps.toml` 里 `transport.tls.enable` 行，重启 |
| 服务器 | 手机连不上 | 8443 是否放行；反代 `Upgrade` 头；证书自签需装信任 |
| PC | frpc 被 Defender 拦 | 加白名单 `%APPDATA%\DSH Link`、`pc\frpc-bin`；或浏览器下载 frpc.exe 放好 |
| PC | 隧道红 | frpc.exe 放好没；服务器 7000 放行；token 一致 |
| 手机 | 登录闪退 | 用修复版（`wss://` bug），见 Android `GatewayClient.connect`，需 `wss://` |
| 手机 | 登录 invalid-credentials | 网关密码与连接串不一致：`sed -i 's/"password": *"[^"]*"/"password": "实际密码"/' /etc/dsh-gateway/config.json && rm -f /var/lib/dsh-gateway/auth.json && systemctl restart dsh-gateway` |
