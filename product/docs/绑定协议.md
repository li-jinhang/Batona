# DSH Link — 产品形态与绑定协议（三端契约）

> 版本 v0.1 · 日期 2026-08 · 状态：实现基线
> 关联：[需求-DSH远程接入网关.md](./需求-DSH远程接入网关.md) · [设计-DSH远程接入网关.md](./设计-DSH远程接入网关.md) · [gateway 代码](../server/gateway)

## 1. 产品定位

**DSH Link**：让 DeepSeek Harness 的使用者用手机随时随地操控自己笔记本上的 DSH，
配置全部收敛到软件内，用户不接触命令行。

| 端 | 形态 | 用户交互 |
|---|---|---|
| **手机** | Android App（Kotlin + Compose） | 扫码/输入绑定 → 登录 → 操控 |
| **PC** | Windows 桌面软件（Electron） | 填服务器连接串（或扫码）→ 一键启动 → 常驻托盘 |
| **服务器** | 一键安装/升级脚本（宝塔终端） | 一条命令安装；更新 = 重新跑一条命令 |

## 2. 拓扑（不变）

```
手机 App ──HTTPS──▶ 服务器(网关+frps) ◀──frp 隧道── PC 软件(DSH web 127.0.0.1:3080)
```

- agent/LLM/工具执行全部在 **PC**；服务器（Ubuntu24 2核2G）只跑 Node 网关 + frps（均为轻量进程）；
- 手机与 PC 不直连，绑定关系通过网关统一管理。

## 3. 绑定协议（三端共同的"连接串"）

### 3.1 连接串格式（`dsh-gw://`）

服务器一键安装完成时生成一段**连接串**，编码了服务器身份与初始凭证：

```
dsh-gw://<服务器IP>?frpPort=7000&frpToken=<token>&gwUser=<admin>&gwPass=<密码>&pair=<配对码>
```

字段：

| 字段 | 含义 | 用途 |
|---|---|---|
| `frpPort` | frps 控制端口 | PC 软件连 frp |
| `frpToken` | frp 认证令牌 | PC 软件写 frpc 配置 |
| `gwUser` / `gwPass` | 网关初始账号 | PC 软件可代为注册/展示 |
| `pair` | **一次性配对码**（8 位字母数字） | PC 软件/手机 App 绑定网关 |

连接串同时编码为 **二维码**（QR 内容即连接串文本），方便 PC/手机扫码。
PC 软件扫服务器安装输出（终端二维码或浏览器页二维码）；手机 App 扫 PC 软件生成的二维码
（PC 软件持有连接串后重新生成，内容相同）。

### 3.2 配对码语义

- 一次性：被任一设备消费（调用 `POST /api/auth/pair`）后失效；
- 消费配对码的设备自动完成"设备注册"，获得一个短期注册令牌；
- 注册令牌换取正式登录（账号密码 + TOTP，与现有网关认证一致）；
- 配对码有效期：生成后 24 小时（服务器脚本生成时写入）。

### 3.3 绑定流程（用户视角）

```
服务器安装 ──▶ 输出连接串/二维码
                    │
        ┌───────────┴───────────┐
        ▼                       ▼
   PC 软件「添加服务器」       手机 App「添加服务器」
   扫码 或 粘贴连接串            扫码 或 粘贴连接串
   写入 frpc 配置（自动）        调 /api/auth/pair 注册设备
   启动 DSH + frpc（自动）      登录（账号密码 + TOTP）
   生成手机配对二维码 ──────▶   （手机亦可扫 PC 二维码）
```

### 3.4 绑定分发（网关零改动）

- 安装脚本在终端输出连接串；同时生成 `web/pair.html`（静态页，含连接串文本 + 复制按钮），
  用户也可在服务器 `http://<IP>:3090/pair.html` 查看（建议仅安装后短期内使用）；
- PC 软件解析连接串后**自动填充**网关账号密码（`gwUser`/`gwPass`），并重新生成二维码供手机扫码；
- 手机 App 解析连接串 → 自动填充登录表单（账号密码来自连接串）→ 用户确认并输入 TOTP 完成登录；
- **认证仍是网关账号密码 + TOTP**（网关 `auth` 层不变）；`pair` 字段保留为绑定标识，
  未来如需"一次性设备注册"可在网关加 `POST /api/auth/pair`，不影响本协议。

## 4. PC 软件（Electron）规格

目录：`product/pc/`（独立 Electron 工程）

### 4.1 主进程能力

| 能力 | 实现 |
|---|---|
| 服务编排 | 状态机：`检测 DSH(3080) → 未运行则启动(dsh web) → 启动 frpc → 在线` |
| DSH 管理 | 探测 `dsh` 命令（PATH / npx 缓存）；spawn `dsh web`；退出时可选停止 |
| frpc 管理 | 内置 `frpc.exe`（首次下载或随包携带）；写 `frpc.toml`；spawn 守护（崩溃重启） |
| 绑定存储 | `userData/binding.json`（连接串解析结果） |
| 配对二维码 | `qrcode` 库生成；主窗口与托盘菜单展示 |
| 开机自启 | `app.setLoginItemSettings({openAtLogin})` |
| 日志 | `userData/logs/`，主窗口日志页展示 |
| 托盘 | 状态图标 + 菜单（打开/状态/二维码/退出） |

### 4.2 界面（渲染进程，vanilla JS，无构建链）

1. **未绑定**：引导页（扫码 → 粘贴连接串 → 手动填 IP+令牌）
2. **已绑定**：状态卡（DSH / 隧道 / 网关 / 手机在线数）+ 手机配对二维码 + 日志 + 设置（自启、端口）

### 4.3 打包

electron-builder → NSIS 安装包 + 便携版。`npm run dist`。

## 5. 服务器一键安装/升级脚本规格

目录：`product/server/install.sh`（宝塔终端运行）

### 5.1 安装（首次）

```bash
bash install.sh --install [--ip 公网IP] [--admin 用户名] [--password 密码]
```

- 幂等：frps 已装则跳过（升级用 --update）；
- 安装 Node（若 <18）→ 网关（取 `gateway/` 同传或 release 包）→ frps → systemd；
- 生成并持久化 `server-info.json`（/etc/dsh-gateway/server-info.json）：
  frp token、admin 账号密码（若未给则随机）、配对码（24h）、公网 IP；
- 输出二维码（终端 ASCII 或提示浏览器访问 `http://IP:3090/pair`）；
- 数据持久化：`/var/lib/dsh-gateway`（auth.json）与 `/etc/dsh-gateway`（配置）**升级不覆盖**。

### 5.2 升级（频繁更新场景）

```bash
bash install.sh --update [--source 本地包路径或release URL]
```

- 停服务 → 校验/解压新包到 `/opt/dsh-gateway/app`（版本目录）→ 重启 systemd → 保留数据/配置/server-info（含配对码续期可选）；
- frps 不随网关更新（极少变更）。

## 6. 手机 App（原生 Android）规格

目录：`product/android/`（完整 Gradle 工程，Kotlin + Jetpack Compose）

### 6.1 依赖

- OkHttp（REST + WebSocket）、kotlinx.serialization、ZXing（扫码）、CameraX
- minSdk 26，targetSdk 34

### 6.2 页面

| 页面 | 内容 |
|---|---|
| 引导 | 扫码 / 粘贴连接串 → 解析 `dsh-gw://` → 调 pair → 登录（账号+密码+TOTP） |
| 主页 | 底部导航：会话 / 工作区 / 模型 / 设备 / 设置 |
| 会话列表 | 新建（选后端+预设）、恢复、状态徽标 |
| 聊天 | 流式渲染、工具卡片、审批按钮、提问表单、取消、模型切换 |
| 设置 | 服务器信息、TOTP 绑定引导、退出登录 |

### 6.3 协议

复用网关前端协议 v1（四象限 RPC 信封，见 [设计文档 §4.2](../设计-DSH远程接入网关.md)）：
`wss://<server>/ws?token=…`，方法 `auth.hello / session.* / workspace.* / model.* / respond / device.*`。
