## What to build

让两个独立账号的 PC 和手机同时完成列表、打开会话、发送、推送与审批；互相猜测资源 ID 仍无法跨账号访问。

把最小链路扩展到并行真实隧道和适配器路由，覆盖全部业务入口而不只会话列表。

## Acceptance criteria

- [ ] AC04 通过：两 PC 不互踢；一方离线、重连和上报 launch token 不改变另一方的连接或认证。
- [ ] 覆盖工作区、目录、会话、模型/权限、历史、发送/取消、审批/提问应答、设备管理及缓存的归属校验。
- [ ] 人为设置相同 backend 会话 ID 与请求 ID，确认账号/PC/backend 复合归属不碰撞。
- [ ] 未认证 WS、已认证但无绑定的 WS、其他账号 WS 收不到目标账号任何业务推送。
- [ ] 持久化和重启后归属仍正确；伪造隧道目标、旧连接迟到事件不能污染新连接。
- [ ] 账号/设备结构预留多设备数量策略；本期仍严格一电脑一手机，不开放新产品能力。
