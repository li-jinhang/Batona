# 05：退出恢复、解绑和更换设备

状态：implemented-candidate。功能已实现；公开 API 生命周期、持久身份和离线发送保护通过，完整 GUI 断网恢复待验收。 具体通过/未运行项见 [验收证据](../evidence.md)；下列完整验收项未全部签收，不自动宣称完成。

## What to build

PC 设备管理展示手机名称、在线状态和最近连接时间，并提供改名/解绑；按既定区别实现关程序、退出登录、换手机和换电脑。

## Blocked by

- [04：两组用户同时使用且完全隔离](04-concurrent-isolation.md)

## Acceptance criteria

- [ ] AC05–AC08 通过；关程序或断网保留登录/绑定，离线不能新增发送队列。
- [ ] 手机退出保留名额、撤销该登录并清理旧缓存；原手机重新扫码经 PC 确认可恢复，不必解绑。
- [ ] 同一设备的判定不能依赖可伪造名称；重装丢失身份按换设备流程处理，并提示用户到 PC 解绑。
- [ ] PC 主动退出立即停止远程使用；原 PC 原密钥重新登录后，未主动退出手机自动恢复。
- [ ] 换手机先解绑；解绑后旧令牌、已打开连接、待审批和重放请求不能继续使用。
- [ ] 新 PC 替换须确认，取消不影响原 PC；确认后旧 PC 断开且不会自动重连抢回，手机需重新配对。
- [ ] 退出/换账号/绑定变更时不得显示旧账号缓存；PC 本地 Agent 任务不因远程退出/解绑而取消。
