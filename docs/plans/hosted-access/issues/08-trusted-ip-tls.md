## What to build

保持客户端预设 IP，让 PC/Android 在 HTTPS/WSS 全路径验证服务端身份；管理员也能通过可信连接使用网页后台，不依赖忽略告警。

## Blocked by

- [03：手机配对后发出第一条请求](03-pair-send.md)

## Acceptance criteria

- [ ] AC11 通过：PC 请求/健康探测/WSS、Android REST/WS 和后台登录均有可信成功与不可信失败证据。
- [ ] 形成可复现的信任材料分发和轮换方案；私钥只留服务端，客户端预置信任须经可信发布渠道。
- [ ] 未知证书、错误 IP 身份和过期证书拒绝且不发送登录密钥；不保留全局 TrustAll 或无条件主机名放行。
- [ ] 验证续期和计划轮换对已发客户端的影响；安装脚本不能意外生成新密钥使所有客户端失联。
- [ ] 证书相关错误有可理解提示，恢复方法不引导用户长期关闭校验；模拟器可完成可信联调。
- [ ] 公网仍仅使用既定 HTTPS/WSS 网关入口，既有首页/下载与其他项目反代不被覆盖。
