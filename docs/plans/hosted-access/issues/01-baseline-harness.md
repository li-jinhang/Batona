## What to build

前置验证任务：在不改动用户现有运行实例的情况下，用临时网关、隔离隧道客户端与假 Agent 重现当前接入行为，为后续纵向功能提供一条可重复验证的链路。

这不是一次全仓重构；若确需调整装配边界，只做测试必需的最小变更。

## Blocked by

无功能依赖；用户已于 2026-09-22 授权开发与隔离测试。

## Acceptance criteria

- [ ] 逐项核对基线清单中既有改动，记录保留方式与后续测试参照，不擅自提交、丢弃或 stash 用户改动。
- [ ] 给出单条可重复运行的本地测试入口，动态端口、独立数据目录；关闭测试不终止用户的 DSH/Codex。
- [ ] 证明假 Agent 的请求受理与任务完成可分开控制，后续能确定计数点和撤销时本地任务状态。
- [ ] 现有测试的通过、失败、未运行分开记录；识别 Codex Desktop writer 限制，不声称完整控制已可用。
- [ ] 记录后续跨端契约需替换的旧描述，未实现部分不提前改写为完成。
