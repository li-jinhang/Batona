## What to build

运营者通过管理页面完成账号生命周期操作，并能观察旧电脑/手机远程权限立即失效；重置得到全新账号。

## Blocked by

- [05：退出恢复、解绑和更换设备](05-device-lifecycle.md)

## Acceptance criteria

- [ ] AC09 通过：禁用无重新启用入口或可调用旁路；旧密钥及既有设备访问全部拒绝。
- [ ] 重置在一致事务边界内撤销旧账号并建立新账号；旧登记及关联统计不继承，失败不能留下两个有效账号或不可判定状态。
- [ ] 删除清除账号及服务器设备登记、关联计数；页面对不可逆影响给予明确确认。
- [ ] 已建立的 HTTP/WS、隧道、待确认配对和重连均服从撤销；进程重启后不恢复已撤销权限。
- [ ] 正在执行的本地任务继续运行，远程流停止；不向本地 Agent 发送取消，不删除 PC 文件/会话。
- [ ] 必要操作记录不含完整密钥、请求正文或被删除账号秘密；后台无用户会话浏览能力。
