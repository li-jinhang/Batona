## What to build

从受控管理页面生成测试账号与备注，查看完整密钥；PC 输入密钥获得自己的登录身份，错误凭据得到明确反馈。此切片覆盖后台、持久化、身份验证与 PC UI。

后续任务才提供手机业务访问；此时未完成配对的客户端无业务控制权。

## Acceptance criteria

- [ ] AC01 通过：用户密钥与管理员密钥不能互用，无需用户注册、用户名密码或 TOTP。
- [ ] 后台支持生成、受控查看与备注修改；真实密钥不出现在日志、URL、普通列表响应或公共页面中。
- [ ] 账号与 PC 设备有独立标识和归属，使用一把有效密钥；服务重启后账号/备注和有效状态保留。
- [ ] 提出并验证可恢复密钥的加密存储与保护密钥管理；仅管理员受控查看界面允许解密回显。
- [ ] 管理员会话保护、失败限速和输入校验有负例；对未启用的手机业务及旧旁路默认拒绝。
- [ ] 用合成密钥完成管理 UI→PC 登录演示，展示状态而不把完整凭据放进报告。
