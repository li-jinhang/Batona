## What to build

已登录 PC 打开临时配对页，Android 扫码或手动输入码，PC 确认后手机经自研隧道向该电脑的假 Agent 发送请求并看到返回状态。

先交付一组设备的最小完整链路，但所有新增资源从创建时即带已认证归属；不以全局共享授权作为过渡产品。

## Acceptance criteria

- [ ] AC02、AC03 通过：同一码不能重复授权；拒绝、关闭页面、断线和确认竞态均有结果，不遗留超额绑定。
- [ ] 最小化保持待配对，断线重连生成新码；已完成配对不因配对页关闭而失效。
- [ ] 手机绑定后 DSH/Codex 入口共用绑定；使用假后端证明请求、状态推送、审批/提问往返的归属。
- [ ] 手机无密码/TOTP/旧连接串输入要求；二维码不含管理员或账号访问密钥。
- [ ] 只准许已确认手机使用目标电脑；伪造账号/电脑 ID、未认证 WS 和旧共享凭据不能绕过。
- [ ] 手动码路径可在独立 Android Studio AVD 上演示；扫码另测拒绝相机权限后的恢复路径。
- [ ] PC 隧道与后端端口只按既有出站/回环模式连接，不引入 FRP 或新的公网后端端口。
